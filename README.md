# ORMA®

Классическая тема для WordPress 6.2+ и PHP 7.4+.

## Установка

1. Загрузите `orma.zip` через «Внешний вид → Темы → Добавить новую → Загрузить тему».
2. Активируйте ORMA. В меню «Внешний вид → Настройка ORMA» нажмите «Создать страницы ORMA». Если страница с таким адресом уже существует, импорт использует её и сохраняет её содержимое.
3. В «Внешний вид → Настроить → ORMA — Контакты» заполните почту для заявок и ссылки на мессенджеры. Форма использует `wp_mail()`. Проверьте получение тестового сообщения на своём хостинге.
4. Материалы блога добавляются через «Записи». До публикации первой записи блог показывает карточки из Figma, а пример статьи доступен отдельной страницей. В портфолио оставлены серые обложки из макета.

## Шаблоны

- `front-page.php` — входной шаблон главной, секции находятся в `templates/home.php`.
- `page-templates/` — назначаемые шаблоны работ, услуг, детальной услуги, страницы «Обо мне», стоимости в трёх вариантах, блога, демостатьи и контактов.
- `single.php` — одиночные записи WordPress. `page.php` — обычные страницы.
- `templates/` — тексты, секции и демонстрационные карточки, перенесённые из Figma. Для правок этих секций используйте PHP-шаблоны.
- `assets/` — локальные изображения, Inter, стили и JS. Сборка после установки не требуется.

На ширине 1440 px тема использует размеры десктопного макета. Мобильная компоновка разработана по десктопным фреймам. Карта сайта из Figma использована для структуры, для неё отдельная страница не создаётся.
